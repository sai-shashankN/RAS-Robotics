# Model X — full-feature target, design stage

X uses the new two opposing curling fingers, retains Beta's powered wrist/claw roll and rotating sleeve and adds the extra arm-to-sleeve swivel, broader manipulation workspace, load-bearing claw support, lifting, and elevated-area assistance. The optional lifted-heading turn is retained as an advanced maneuver; wheel steering handles normal turns.

No runnable X simulation is claimed yet. Its joint arrangement, support loads, and contact-control design are deferred while Alpha is developed.

See [Model X specification](../../project-notes/models/MODEL_X.md). Gamma and Delta have not been assigned features or created as models.

The three-finger tripod assumption is superseded. Reassess two-finger ground footprint, pad width, load paths and tipping/sliding stability; roll does not add another ground contact.

## Latest roadmap clarification — 24 October 2026

Alpha-A is the existing front/back pinch configuration; Alpha-B is the otherwise matching fixed left/right comparison, specified but not generated/run. Beta targets powered full 360-degree claw orientation, with useful task testing and separate movement-limit exploration. Its roll joint is not implemented yet. A/B results inform Beta without validating intermediate angles or added-joint dynamics.

The circular palm remains a prototype proxy; a compact bridge/rectangular palm is a proposed comparison. Alpha/Beta claws are for manipulation. Reopen the claw design for robot-weight support/lifting at X time. See [the comparison plan](../../project-notes/GRIPPER_COMPARISON.md).
